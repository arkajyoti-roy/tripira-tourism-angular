Accessibility Help:

Use the accessibility options provided in this Web site to control the screen display. These options allow increasing the text size for better readability.

Changing Text Size:

Changing the size of the text refers to making the text appearing smaller or bigger from its standard size. There are three options provided to you to set the size of the text that affects the readability. These are:

  • Large - Displays information in the large font size. Select large text image for increasing the text size.
  • Small - Displays information in the small font size. To decrease the text size select small text image displayed on the top of the page.

Help on search facility:

Using the Search Facility -

  • Simple search will be available on home page from where user can search on basis of text/word and keyword available in document/Tenders-picture etc.

Searching Tips -

  • When searching, don't enter plural terms such as "press releases" because the server will script all documents with release information the title or keywords. If you enter release (singular), the server will list articles with both release and releases.
  • All searches are case-insensitive. That is, words are looked for regardless of capitalization.
